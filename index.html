🔐 Código Secreto

Intentos: 0/8
Has encontrado una caja fuerte.

La caja tiene una cerradura de cuatro cifras. Encima hay tres pistas.

Tu misión es descubrir el código antes de quedarte sin intentos.
🔐

Descubre el código

Pista 1: El primer número es 1.

Pista 2: El segundo número es el doble del primero.

Pista 3: El tercer número es el segundo número + 2.

Pista 4: El cuarto número es el tercer número - 1.

🔓

¡Código correcto!

La caja fuerte se abre.

Dentro encuentras una tarjeta que dice:

"Enhorabuena. Tu capacidad de deducción te ha permitido superar el desafío."
